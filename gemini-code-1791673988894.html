How to Host Your Own Website

Option 1: GitHub Pages (Free & Easy)

  1. Create a free account on GitHub.
  2. Create a new public repository named huztiers.
  3. Save this website code as a file named index.html.
  4. Upload/commit index.html to your repository.
  5. Go to repository Settings > Pages, set branch to main, and save. Your site will be live at https://yourusername.github.io/huztiers!

Option 2: Netlify Drop (Instant Drag & Drop)

  1. Save this website code as index.html on your computer.
  2. Visit Netlify Drop.
  3. Drag and drop the folder containing your index.html file onto the browser page. Netlify will deploy it instantly with a live URL!
